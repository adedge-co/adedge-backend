refactor: 이메일 인증 기능을 별도 패키지로 분리

## 주요 변경사항

### 패키지 구조 개선
- 이메일 인증 기능을 `app/users/`에서 `app/email/`로 분리
- SMS 패키지와 동일한 구조로 통일

### 신규 패키지 생성
- `app/email/` 패키지 생성
  - `routers/router.py`: 이메일 인증 엔드포인트 (POST /email/send, /email/verify)
  - `schema/schemas.py`: 이메일 인증 관련 스키마
  - `services/email_client.py`: SMTP 이메일 전송 클라이언트
  - `services/email_verification_service.py`: 이메일 인증번호 발송/검증 서비스
  - `services/email_templates.py`: HTML 이메일 템플릿

### 엔드포인트 변경
- 기존: `POST /auth/email/send`, `POST /auth/email/verify`
- 변경: `POST /email/send`, `POST /email/verify`

### 수정된 파일
- `app/core/app_factory.py`: 이메일 라우터 등록 및 `/email/**` 경로 허용 추가
- `app/users/routers/router.py`: 이메일 관련 엔드포인트 제거
- `app/users/schema/schemas.py`: 이메일 관련 스키마 제거

### 삭제된 파일
- `app/users/services/email_client.py`
- `app/users/services/email_verification_service.py`
- `app/users/services/email_templates.py`

## 개선 효과
- 코드 구조 일관성 향상 (SMS와 동일한 패키지 구조)
- 관심사 분리: 사용자 관리와 이메일 인증 기능 분리
- 유지보수성 향상: 각 기능별 독립적인 패키지 구조
